
# Retail Sales and Customer Analysis

**Data Analyst Portfolio Project | SQL + Power BI**

## Project Overview

This portfolio project demonstrates retail sales analysis using SQL and Power BI.

The SQL project focuses on customer, product, order, and sales analysis using SQLite. The Power BI project presents sales performance and customer insights through an interactive dashboard.

## Tools & Technologies

- SQL
- SQLite
- Power BI Desktop
- DAX
- Microsoft Excel

The SQL project contains the following tables:

- Revenue: SAR 15,700.00

## Business Questions

This project explores the following business questions:

1. How much revenue does the business generate?
2. Which cities contribute the most sales?
3. Which months have the highest and lowest sales?
4. Which product categories perform best?
5. Which customers contribute the most revenue?
6. What is the order-status distribution?
7. How can sales performance be improved?

## Business Value

The analysis helps understand sales performance, identify high-performing cities and product categories, analyse customer contributions, and discover monthly sales patterns.
